# Payment methods [Available methods and how to choose one]

Payment methods define how a buyer pays a seller for a resource protected by the Machine Payments Protocol. Each method specifies its payment rails, Credential format, and verification logic.

## Status and capabilities

|---|---|---|---|---|

- **Production**: used for live payments today.
- **Available**: SDK published by its maintainer; ask the maintainer about production readiness.
- **¹ Session experimental**: Stellar's session intent (`channel` in its SDK) uses an unaudited contract and a draft spec.

## Overview

When a server responds with `402` Payment Required, the `WWW-Authenticate` header includes a `method` parameter indicating which payment method to use. If supported, the client can then use the corresponding payment method to generate a Credential and retry the request.
