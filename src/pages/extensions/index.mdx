# Extensions [Build on the core payment flow]

Extensions add optional capabilities on top of the core MPP flow. Use them independently—none changes how payment works.

| Extension | Use it to |
|---|---|
| [**Discovery**](/extensions/discovery) | Advertise your API's payment terms so clients and agents know prices before they request |
| [**Identity**](/extensions/identity) | Require a verified email, your own identity provider, an agent signature, or an allowed payer |
| [**Payment hooks**](/extensions/payment-hooks) | Observe client and server payment lifecycles |
| [**Refunds**](/extensions/refunds) | Return funds after a charge, or refund unused session deposits |
| [**Relays**](/extensions/relays) | Delegate payment verification and broadcast to a relay service |

For community-built packages, see [Third-party extensions](/extensions/third-party).
