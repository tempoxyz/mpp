# Client [Handle `402` responses automatically]

The client wraps `httpx`, selects a supported Challenge, creates a Credential, and retries the request.

## Quick start

```python [client.py]
from mpp.client import Mpp
from mpp.methods.tempo import OUSD, TempoAccount
from mpp.methods.tempo import client as tempo

account = TempoAccount.from_key("0x...")
method = tempo.charge(
    account=account,
    allowed_chain_ids=[4217],
    currency=OUSD,
    max_amount="0.50",
    max_amount_decimals=6,
)

async with Mpp(
    allowed_origins=["https://api.example.com"],
    methods=[method],
) as payment:
    response = await payment.fetch("https://api.example.com/resource")
```

`allowed_origins` authorizes automatic payment only to exact HTTP origins. An empty list disables automatic payment. Also configure method-level amount, chain, currency, and recipient limits when you know them.

## Use an existing `httpx` client

```python [client.py]
import httpx
from mpp.client import Mpp

payment = Mpp(methods=[method])

async with httpx.AsyncClient(transport=payment.payment_transport) as client:
    response = await client.get("https://api.example.com/resource")
```

Call `payment.client()` when you want the SDK to construct the `httpx.AsyncClient`.

## Event handling

```python [client.py]
from mpp.client import Mpp
from mpp.events import PAYMENT_RESPONSE

payment = Mpp(methods=[method])

unsubscribe = payment.on(
    PAYMENT_RESPONSE,
    lambda payload: print(payload["response"].status_code),
)
```

`on_challenge_received`, `on_credential_created`, `on_payment_failed`, and `on_payment_response` register named handlers. Each registration returns an unsubscribe function.

## Custom transport

```python [transport.py]
import httpx
from mpp.client import PaymentTransport

transport = PaymentTransport(
    allowed_origins=["https://api.example.com"],
    inner=httpx.AsyncHTTPTransport(retries=3),
    methods=[method],
)

async with httpx.AsyncClient(transport=transport) as client:
    response = await client.get("https://api.example.com/resource")
```

For manual Challenge and Credential handling, see [Core types](/sdk/python/core).
