# Rust SDK [The mpp Rust library]

The `mpp` crate provides payment-aware HTTP clients, server verification, and protocol primitives.

## Install

```bash [test.sh]
$ cargo add mpp --features tempo,client,server
```

Add `middleware` for `reqwest-middleware`, `axum` for the Axum extractor, or `ws` for WebSocket sessions.

## Quick start

### Server

```rust
use mpp::server::{tempo, Mpp, TempoConfig};
use mpp::{format_www_authenticate_many, parse_authorization};

let payment = Mpp::create(tempo(TempoConfig {
    recipient: "0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266",
}))?;

let challenges = payment.charge("0.50")?;
let headers = format_www_authenticate_many(&challenges)?;
// Return every header value with the 402 response.

let credential = parse_authorization(authorization)?;
let receipt = payment.verify_charge(&credential, "0.50").await?;
```

`charge` returns one Challenge per accepted currency. Return every value so the client can choose a supported stablecoin. `verify_charge` binds verification to the route price and rejects a Credential issued for another route.

### Client

```rust
use mpp::client::{Fetch, TempoProvider};
use mpp::PrivateKeySigner;

let signer: PrivateKeySigner = "0xac0974bec...".parse()?;
let provider = TempoProvider::new(signer, "https://rpc.tempo.xyz")?;

let response = reqwest::Client::new()
    .get("https://api.example.com/paid")
    .header("Accept-Payment", "tempo/charge")
    .send_with_payment(&provider)
    .await?;
```

Automatic payment requires an explicit request-level `Accept-Payment` header by default.

## Feature flags

| Feature | Description |
|---|---|
| `axum` | Axum extractors |
| `client` | Client providers and the `Fetch` extension trait |
| `evm` | Shared EVM types and signing |
| `middleware` | `reqwest-middleware` integration |
| `server` | Server verification |
| `stripe` | Stripe Shared Payment Token support |
| `tempo` | Tempo support, including `evm` |
| `tower` | Tower server middleware |
| `ws` | WebSocket transport |

### Common combinations

```toml
mpp = { version = "0.18.1", features = ["client", "tempo"] }
mpp = { version = "0.18.1", features = ["server", "tempo"] }
mpp = { version = "0.18.1", features = ["client", "middleware", "tempo"] }
mpp = { version = "0.18.1", features = ["axum", "server", "tempo"] }
```
