# `tempo.session` [Sessions client method]

## Choose a signing account

<SigningAccountTabs />

Creates the low-level [Sessions](/payment-methods/tempo/session) client method for `Mppx.create`.

:::info
Use [`tempo.session.manager()`](/sdk/typescript/client/Method.tempo.session-manager) for standalone `.fetch()`, `.topUp()`, `.close()`, `.sse()`, and `.ws()` methods.
:::

Uses the [TIP-1034](https://tips.sh/1034) reserve precompile to hold deposits and settle payments.

## Automatic open retries

`Fetch.from` and `Mppx.create` keep automatic opens provisional until the server accepts the response or acknowledges the open with a matching Receipt or snapshot. Rejected or unacknowledged opens retry on the next paid request. Opens sharing a payment scope and channel store are serialized.

Direct Credential creation and `tempo.session.manager()` keep explicit lifecycle ownership.

## Origin-bound recovery

- Fetch binds saved channels to the request's HTTP or HTTPS origin. Use a separate `channelStore` per origin; mismatched or originless entries are rejected.
- Recovering an unknown channel from a snapshot requires a trusted `origin` pin or caller-supplied `descriptor`. Configure the pin yourself, never from an untrusted Challenge.
- Direct Credential creation without Fetch also needs the pin to bind saved channels to your API.

```ts twoslash
import { tempo } from 'mppx/client'
import { privateKeyToAccount } from 'viem/accounts'

const method = tempo.session({
  account: privateKeyToAccount('0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80'),
  allowedChainIds: [42431], // Tempo testnet (Moderato)
  // [!code hl:start]
  currencies: ['0x20c0000000000000000000006a37DA5C996874BE'], // OUSD on Tempo
  decimals: 6,
  maxAmount: '0.01',
  maxDeposit: '1',
  origin: 'https://api.example.com',
  // [!code hl:end]
})
```

Migrate originless entries only after verifying their origin and descriptor against trusted state. Never assign the next request's origin or delete funded channels to bypass this check; preserve them for recovery.

### allowCustomEscrow (optional)

- **Type:** `boolean`
- **Default:** `false`

Accepts the server's noncanonical reserve contract. Enable only for a trusted deployment. Stored channels remain bound to the resolved contract address.

### allowedChainIds (optional)

- **Type:** `readonly number[]`

Allowed Tempo chain IDs; use `[4217]` for mainnet.

- One entry supplies an omitted `chainId`; multiple entries require a Challenge or resolved-client chain.
- An empty list rejects all chains.
- Checked before resolution and signing; a conflicting resolved-client chain is rejected.

### autoSwap (optional)

- **Type:** `boolean | { fallback?: boolean; maxAmountIn?: bigint; slippage?: number; tokenIn?: Address[] }`

Acquires only the missing session currency before opens and top-ups.

- `slippage` accepts `0`–`50` percent.
- The default budget assumes 1:1 token units plus slippage; set a positive `maxAmountIn` in input-token base units for non-parity pairs.
- Per-Credential overrides also apply to automatic HTTP and SSE top-ups.

Default sources: pathUSD, USDC.e, then OUSD. Custom `tokenIn` tokens are tried first; add `fallback: false` to exclude defaults.

### channelStore (optional)

- **Type:** `ChannelStore`

Pluggable persistence for reusable channels. Defaults to an in-memory store. Use a separate store per HTTP origin; existing origin bindings cannot be changed during reuse.

### currencies (optional)

- **Type:** `readonly Address[]`

Case-insensitive allowlist of session currencies. An empty list rejects all offers. Required with `maxAmount` or `maxAtomicAmount`.

### decimals (optional)

- **Type:** `number`
- **Default:** `6`

Token decimals for parsing human-readable amounts. Set this explicitly with `maxAmount`; omitting it rejects that cap rather than assuming six decimals.

### escrow (optional)

- **Type:** `Address`

Exact reserve contract address pin. The server-advertised address must match this value, even when `allowCustomEscrow` is `true`.

### expectedRecipients (optional)

- **Type:** `readonly Address[]`

Case-insensitive allowlist of channel payees. Offers to other recipients, or without a recipient, are skipped during selection and rejected before signing. Explicit closes remain available outside this policy.

### getClient (optional)

- **Type:** `(parameters: { chainId?: number }) => MaybePromise<Client>`

Function that returns a viem client for the given chain ID.

### maxAmount (optional)

- **Type:** `string`

Maximum display-unit price per session unit (Challenge `amount`), not total spend.

- Requires `currencies` and explicit `decimals`; excess fractional digits are rejected.
- Checked during selection, before signing, and before automatic top-ups.
- Explicit closes are exempt.

### maxAtomicAmount (optional)

- **Type:** `string`

Maximum per-unit price in raw base units. Requires `currencies`. Checked alongside `maxAmount` when both are set.

### maxDeposit (optional)

- **Type:** `string`

Maximum deposit in human-readable units. Caps server-suggested channel opens and automatic top-ups.

### onChannelUpdate (optional)

- **Type:** `(entry: ChannelEntry) => void`

Called whenever channel state changes.

### origin (optional)

- **Type:** `string`

Trusted HTTP or HTTPS origin for Credential creation and snapshot recovery. Fetch's request origin must match this pin. Unknown-channel recovery requires this pin or an explicit descriptor; see [origin-bound recovery](#origin-bound-recovery).

### resolveAccount (optional)

- **Type:** `ResolveAccount`

Selects the account that signs this session Credential after the Challenge is known.

### topUpAmount (optional)

- **Type:** `string`

Preferred automatic top-up size in human-readable units. When omitted, `mppx` uses a bounded server `suggestedDeposit`, then the exact shortfall.

## Credential context

Omit context for automatic channel management. Pass it to `method.createCredential()` for manual Credentials or per-call overrides.

```ts
type SessionContext = {
  account?: Account
  action?: 'open' | 'topUp' | 'voucher' | 'close'
  additionalDeposit?: string
  additionalDepositRaw?: string
  autoSwap?: boolean | { fallback?: boolean; maxAmountIn?: bigint; slippage?: number; tokenIn?: Address[] }
  channelId?: Hex
  cumulativeAmount?: string
  cumulativeAmountRaw?: string
  depositRaw?: string
  descriptor?: ChannelDescriptor
  transaction?: Hex
}
```

| Field | Description |
|---|---|
| `account` | Account override for this Credential only. |
| `action` | Manual Credential action. Omit for automatic session management. |
| `autoSwap` | Request-local swap policy, including automatic HTTP and SSE top-ups. Omit to inherit the configured policy. |
| `channelId` | Channel ID to reuse or manually operate on. |
| `descriptor` | TIP-1034 descriptor required for recovery and manual Credentials. |
| `transaction` | Signed Tempo transaction for manual `open` or `topUp` Credentials. |
| `cumulativeAmount` | Human-readable cumulative voucher authorization, parsed with `decimals`. |
| `cumulativeAmountRaw` | Raw cumulative voucher authorization. Takes precedence over `cumulativeAmount`. |
| `additionalDeposit` | Human-readable top-up amount, parsed with `decimals`. |
| `additionalDepositRaw` | Raw top-up amount. Takes precedence over `additionalDeposit`. |
| `depositRaw` | Raw opening deposit override for automatic open Credentials. |
