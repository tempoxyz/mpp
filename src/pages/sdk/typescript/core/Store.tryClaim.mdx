# `Store.tryClaim` [Claim replay keys atomically]

Records the first use of a replay key until its expiration time.

## Usage

```ts twoslash
import { Store } from 'mppx'

const store = Store.memory()
const expires = Date.now() + 60_000

const claimed = await Store.tryClaim(store, 'request:abc123', expires) // [!code hl]
console.log(claimed)
// @log: true

const replayed = await Store.tryClaim(store, 'request:abc123', expires)
console.log(replayed)
// @log: false
```

- Use the store's native `tryClaim` when available; otherwise use [atomic `update`](/sdk/typescript/core/Store.sql#return-type).
- Reclaim expired replay markers; existing values without the [marker shape](#support-replay-claims-in-a-custom-store) remain claimed.
- Return `false` if expiry passes during a native claim operation.

### Support replay claims in a custom store

Implement optional `AtomicStore.tryClaim` as one insert-if-absent-with-expiry operation. Reject non-finite expiries and check `expires <= Date.now()` inside it, not just before asynchronous work. Without this fast path, include `ReplayMarker` in the store's item map:

```ts
type TryClaim<itemMap extends StoreItemMap = StoreItemMap> = <
  key extends keyof itemMap & string,
>(key: key, expires: number) => boolean | Promise<boolean>

// [!code hl:start]
type ReplayMarker = {
  expires: number
  type: 'mppx:replay'
}
// [!code hl:end]
```

### Compose a native claim implementation

`Store.from` preserves an adapter’s native `tryClaim` and applies `keyPrefix` to its keys:

```ts [store.ts]
import { Store } from 'mppx'

const adapter = Store.upstash({
  del: (key) => redis.del(key),
  get: (key) => redis.get(key),
  set: (key, value) => redis.set(key, value),
  update: (key, fn) => atomicUpdate(redis, key, fn),
})

const store = Store.from(
  {
    ...adapter,
    // [!code hl:start]
    async tryClaim(key, expires) {
      if (!Number.isFinite(expires) || expires <= Date.now()) return false
      const result = await redis.set(key, { expires, type: 'mppx:replay' }, {
        nx: true,
        pxat: expires,
      })
      return result === 'OK'
    },
    // [!code hl:end]
  },
  { keyPrefix: 'mppx:' },
)
```

Use absolute Unix-millisecond expiry (Upstash `pxat` or Redis `PXAT`), not a duration. Validate expiry backend-side where needed to prevent already-expired inserts.

[SQL](/sdk/typescript/core/Store.sql) and [Durable Object](/sdk/typescript/core/Store.durableObject) stores include native claims. [Replay sharding](/sdk/typescript/core/Store.durableObject#shard-replay-claims) keeps claims in reusable objects, separate from values: `get` excludes them; `delete` releases them.

## Return type

```ts
type ReturnType = boolean | Promise<boolean>
```

Returns `true` for a new claim; `false` for an existing live claim or a non-finite or expired expiry.

## Parameters

### expires

- **Type:** `number`

Future, finite Unix-millisecond expiry.

### key

- **Type:** `string`

Key to claim; typed stores restrict it to item-map keys.

### store

- **Type:** `Store.AtomicStore`

Atomic store that persists the claim.
