# `EmailOtp.Constants` [Email OTP integration values]

Exports the headers, paths, type, and code-entry limit used by the email one-time-code extension. An issuer service emails a code and exchanges it for a signed attestation token confirming inbox access for one API origin.

## Usage

```ts twoslash
import * as EmailOtp from 'mppx/extensions/identity/email-otp'

console.log(EmailOtp.Constants.header) // [!code hl]
// @log: Identity-Attestation
```

## Properties

### codeAttempts

- **Type:** `3`

Maximum code prompts per acquisition in [`Client.prover`](/sdk/typescript/client/EmailOtp.prover). Only issuer `400` responses trigger another prompt.

### header

- **Type:** `'Identity-Attestation'`

Request header carrying bearer attestations. Comma-separated values can carry several tokens. Keep tokens at their intended API origin; forwarding can expose a reusable session-like credential.

### otpPath

- **Type:** `'/email/otp'`

Issuer endpoint used by [`Client.sendCode`](/sdk/typescript/client/EmailOtp.sendCode).

### requiredHeader

- **Type:** `'Identity-Attestation-Required'`

Rejection response header naming the required type and trusted issuer, such as `email;issuer="https://identity.mpp.tempo.xyz"`.

### type

- **Type:** `'email'`

Attestation type this extension accepts. It isn't a generic phone or KYC attestation API.

### verifyPath

- **Type:** `'/email/verify'`

Issuer endpoint used by [`Client.verifyCode`](/sdk/typescript/client/EmailOtp.verifyCode).
