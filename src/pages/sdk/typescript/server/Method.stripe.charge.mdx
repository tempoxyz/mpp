# `stripe.charge` [Deprecated SPT constructor]

Deprecated alias of [`stripe.spt`](/sdk/typescript/server/Method.stripe.spt).

Use `stripe.spt()` for server-side Shared Payment Token payments.

## Usage

```ts twoslash [server.ts]
import Stripe from 'stripe'
import { stripe } from 'mppx/server'

const client = new Stripe(process.env.STRIPE_SECRET_KEY!)

const method = stripe.spt({
  client,
  networkId: process.env.STRIPE_NETWORK_ID!,
  paymentMethodTypes: ['card'],
})
```
