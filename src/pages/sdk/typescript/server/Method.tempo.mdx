# `tempo` [Register default Tempo intents]

## Choose a signing account

<SigningAccountTabs />


Preferred convenience function that creates both `tempo.charge` and Sessions method intents with shared configuration.

Use `tempo(...)` by default. Use `tempo.common(...)` only when you want to make the shared charge and Sessions behavior explicit; it is an alias for `tempo(...)`.

Register [`tempo.subscription`](/sdk/typescript/server/Method.tempo.subscription) separately for recurring payments.

:::warning[Legacy Sessions]
`mppx` 0.13.0 removed the deprecated Legacy Sessions client exports. Close or settle Legacy channels before upgrading because current Sessions don't share their channel state.
:::

## Usage

By default, offer OUSD first with USDC.e as the mainnet fallback. `testnet: true` offers OUSD then pathUSD on Moderato.

```ts twoslash
import { Mppx, Store, tempo } from 'mppx/server'
import { privateKeyToAccount } from 'viem/accounts'

const account = privateKeyToAccount('0x0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef')

Mppx.create({
  methods: [
    // [!code focus:start]
    tempo({
      account,
      chainId: 4217,
      machineTokenEnabled: true,
      recipient: '0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266',
      store: Store.memory(),
    }),
    // [!code focus:end]
  ],
})
```

You can also register the intents separately:

```ts twoslash
import { Mppx, Store, tempo } from 'mppx/server'
import { privateKeyToAccount } from 'viem/accounts'

const account = privateKeyToAccount('0x0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef')

Mppx.create({
  methods: [
    tempo.charge({
      machineTokenEnabled: true, // [!code hl]
      recipient: '0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266',
    }),
    tempo.session({
      account,
      chainId: 4217,
      store: Store.memory(),
    }),
  ],
})
```

### Accept only OUSD

Pass an explicit list to replace the defaults. Resolve the OUSD address from viem on mainnet:

```ts twoslash
import { Mppx, tempo } from 'mppx/server'
import { ousd } from 'viem/tokens'

const mppx = Mppx.create({
  methods: [tempo({
    currencies: [ousd(4217).address], // [!code hl]
    recipient: '0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266',
  })],
})
```

For multiple currencies, pass an ordered list of addresses or token definitions. For example, `currencies: tokens.tempo` with `tokens` from `viem/tokens` accepts its USD tokens deployed on the configured chain. An explicit list can expand acceptance as the installed registry changes; omit it to keep the SDK's OUSD-first defaults.

Viem `2.57.1` doesn't include a Moderato OUSD entry. Use the SDK defaults on Moderato; a token definition without an entry for that chain is skipped.

## Return type

```ts
type ReturnType = readonly [Method.Server, Method.Server, ...Method.Server[]]
```

An ordered group containing a charge and session method for each currency: OUSD charge, OUSD session, then the fallback pair. `Mppx.create` flattens the group automatically. Session offers share storage and settle each channel in its own currency.

## Parameters

Accepts the shared configuration of [`tempo.charge`](/sdk/typescript/server/Method.tempo.charge) and [`tempo.session`](/sdk/typescript/server/Method.tempo.session) parameters. The most common are listed below.

### account (optional)

- **Type:** `Account`

Account used to sign Tempo transactions and receive payments by default.

### allowedFeeTokens (optional)

- **Type:** `readonly Address[]`

Restricts transaction fee tokens for sponsored charges. Applies only to the charge offers; see [`tempo.charge`](/sdk/typescript/server/Method.tempo.charge#allowedfeetokens-optional).

### canOffer (optional)

- **Type:** `Method.CanOfferFn`

Returns whether each configured Tempo offer is available when an HTTP handler composes multiple offers. The hook receives the normalized, immutable payment request and a clone of the incoming `Request`.

### chainId (optional)

- **Type:** `number`

Defaults to mainnet (`4217`), or Moderato (`42431`) with `testnet: true`. An explicit `chainId` takes precedence; set it when `getClient` uses another network.

### currencies (optional)

- **Type:** `readonly (string | Token)[]`
- **Default:** OUSD, then USDC.e on mainnet; OUSD, then pathUSD on Moderato

Ordered accepted token addresses or USD token definitions from `viem/tokens`. An explicit list replaces the defaults; `currencies: [ousd(4217).address]` accepts only OUSD on mainnet. Token definitions resolve against `chainId`; unavailable and non-USD tokens are skipped, and duplicate addresses are removed. An empty resolved list throws. Ordering controls presentation, not client selection or automatic swaps.

### currency (optional, deprecated)

- **Type:** `string`

Accepts one token address. Use `currencies: [currency]` instead. Don't set both options. Wire Challenges and per-handler overrides still use singular `currency`.

### decimals (optional)

- **Type:** `number`
- **Default:** `6`

Decimal places for amount parsing.

### feePayer (optional)

- **Type:** `Account | { fetch?: typeof globalThis.fetch; headers?: Readonly<Record<string, string>>; url: string } | string | true`

Account or remote service for sponsoring transaction fees. Pass a viem `Account` to co-sign locally, a URL string to use a remote [fee payer service](https://docs.tempo.xyz/sdk/typescript/server/handler.feePayer), an object with `fetch`, `headers`, and `url` to customize remote requests, or `true` when the `account` parameter doubles as the fee payer. The custom `fetch` handles only fee-payer JSON-RPC traffic. `mppx` reserves the `Content-Type` header for JSON.

### getClient (optional)

- **Type:** `(parameters: { chainId?: number }) => MaybePromise<Client>`

Function that returns a viem client for the given chain ID. Overrides the default RPC configuration.

### machineTokenEnabled (optional)

- **Type:** `boolean`

Lets compatible charge clients fund the requested stablecoin payment with MACH through the canonical swapper. This option applies only to `tempo.charge`; it doesn't change Sessions.

### onPaymentSuccess (optional)

- **Type:** `Method.OnPaymentSuccessFn<typeof tempo.Methods.charge> & Method.OnPaymentSuccessFn<typeof tempo.Methods.session>`

Runs after a configured Tempo charge or Sessions result succeeds. The hook receives the optional associated Challenge, canonical request, its Receipt, the HTTP input when available, and the resolved pre-transform `requestInput` when route options are available. Errors don't change payment handling.

### recipient (optional)

- **Type:** `Address`

Default recipient address for payments.

### testnet (optional)

- **Type:** `boolean`

Testnet mode. Defaults the chain ID to `42431` (Tempo testnet).
