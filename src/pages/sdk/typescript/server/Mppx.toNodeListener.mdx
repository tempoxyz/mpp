# `Mppx.toNodeListener` [Adapt payments for Node.js HTTP]

Wraps a payment handler to create a Node.js HTTP listener.

## Usage

```ts twoslash
import * as http from 'node:http'
import { Mppx, tempo } from 'mppx/server'

const mppx = Mppx.create({
  methods: [tempo.charge()],
})

http.createServer(async (req, res) => {
  const result = await Mppx.toNodeListener(
    mppx.charge({
      amount: '0.1', 
      currency: '0x20c0000000000000000000006a37DA5C996874BE', // OUSD on Tempo
      recipient: '0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266',
    }),
  )(req, res)

  if (result.status === 402) return

  res.end('OK')
})
```

## Behavior

- **On an oversized body:** Writes `413 Payload Too Large`. Request bodies default to a 10 MiB limit.
- **On `402`:** Writes the Challenge response headers and body, then ends the connection.
- **On `200`:** Sets the `Payment-Receipt` header; the caller writes the response body.

## Return type

```ts
type ReturnType = (
  req: IncomingMessage,
  res: ServerResponse,
) => Promise<MethodFn.Response<Transport.Http>>
```

## Parameters

### handler

- **Type:** `(input: Request) => Promise<MethodFn.Response<Transport.Http>>`

The payment handler function returned by calling an intent on the payment object.

### options (optional)

- **Type:** `{ host?: string; maxBodySize?: number; protocol?: string }`

Configures Node-to-Fetch request conversion. `maxBodySize` defaults to `10_485_760` bytes (10 MiB).
