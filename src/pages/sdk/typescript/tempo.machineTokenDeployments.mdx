# `machineTokenDeployments` [Canonical MACH funding contracts]

Provides the canonical MACH token and swapper addresses for Tempo mainnet and Moderato testnet.

## Usage

```ts twoslash
import { machineTokenDeployments } from 'mppx/tempo'

const deployment = machineTokenDeployments[4217] // [!code hl]

console.log(deployment.token)
// @log: 0x20c000000000000000000000f37de3740ADec032
```

Use these addresses to inspect or allowlist the contracts used by [`machineTokenEnabled`](/sdk/typescript/server/Method.tempo.charge#machinetokenenabled-optional). Continue to advertise the stablecoin you want to receive as the charge currency—servers can't advertise MACH as the settlement currency.

Replace `mach(chainId).address` from earlier releases with `machineTokenDeployments[chainId].token`.

### Funding link

When a buyer lacks MACH, send them to the Tempo Wallet onramp: `https://wallet.tempo.xyz/agent?action=fund&intent=mach&chainId=4217`. Add `&address=<buyer address>` when you know the payer and `&amount=<USD shortfall>` (at most two decimal places, rounded up to the cent). The link works only for Tempo mainnet. See [When the buyer has no MACH](/payment-methods/tempo/charge#when-the-buyer-has-no-mach) for error responses and agent-facing wording.
